# 评审协议（3 评委 + 1 Critic，盲评）

## 输入（盲包）

- 候选物：文案 / 封面描述 / 分镜
- **去标识历史摘要**（必填）：作者近 30 条的「形式 + 结构 + 未用过的做法」，不含身份、不含数据
- `taste/rubric.md` 当前版本
- `taste/benchmarks.md`

> 历史摘要为什么必须：R5（超越度）和 V3（连续性）都需要「作者过去怎么做」，但盲评又要去掉作者身份。摘要是这两者唯一的兼容解。

历史摘要模板：

```
【作者历史摘要（去标识）】
近 30 条形式：<如 白底大字图 + 清单 + 数字标题>
出现过的结构：<列举>
从未出现过的做法：<列举——R5 靠这一栏判断越界>
视觉语言：<字体 / 主色 / 版式>
```

## 角色

| 角色 | 视角 | 禁止 |
|---|---|---|
| P1 | 目标受众：第一眼会不会停 | 不看另两位分数 |
| P2 | 竞品/同类：有没有更新鲜的做法 | 同上 |
| P3 | 平台规则与分发：限流风险、完播结构 | 同上 |
| C | Critic：只审理由是否成立 | 不打分 |

## 流程

1. 准备盲包（含历史摘要）
2. 三个 subagent **并行**，各按 rubric 打分，输出逐项分数 + 一句理由
3. 汇总：Δ≥2 的项标红
4. **若总分落在 9–11，强制复评一次**（补历史摘要或换评委）
5. C 复核：挑战分歧项与最高分项，指出「哪条理由站不住」
6. 结论：淘汰 / 候选 / 可发布 + 必须修改项 + 反对意见

## 输出格式（固定）

```
候选：<一句话>
总分：<n>/16    判定：<淘汰|候选|可发布|复评>

R1 n  R2 n  R3 n  R4 n  R5 n  V1 n  V2 n  V3 n
（R2 附 R2a/R2b）

分歧项（Δ≥2）：<项>
必须修改：1) ... 2) ...
反对意见：<如果我是对立面，我攻击这一条>
```

## 无效评审

- 没有反对意见
- 三个评委逐项分数完全一致（等于一个人评了三次）
- 用了过期或被标 retired 的 benchmark
- 盲包里没有历史摘要，却仍给出 R5 / V3 分数

## 手动跑（Phase 1 之前）

用 DSH 的 `subagent` 开三个，分别给 P1/P2/P3 视角提示词，互不可见；最后自己当 C。
